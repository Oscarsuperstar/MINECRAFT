Modding basics (Simple)

Language

Most Minecraft Java mods/plugins use Java. You write code, compile it, and give the plugin to a server or mod loader.

APIs

Spigot/Bukkit and Paper are popular server APIs for plugins. Fabric and Forge are used for client/server mods.

How to test

Run a local test server. Copy your plugin/mod file into the server's plugins/mods folder and restart.

Worked example — Simple PvP QoL Plugin

Goal: Add a small PvP feature that shows a player a health bar with names during combat and gives a small speed boost for quick escapes.

// Example (pseudo-Java for a Bukkit/Spigot plugin)

// 1) Listen for when a player damages another player
public void onPlayerDamage(PlayerDamageEvent e) {
  if (e.getTarget() is Player && e.getAttacker() is Player) {
    // 2) Show the target's health above their name (client-side display)
    showNameplateHealth(e.getTarget());

    // 3) Give attacker a tiny speed boost for 3 seconds
    addSpeedBoost(e.getAttacker(), durationSeconds=3, level=1);
  }
}

// 4) Put compiled plugin jar into server/plugins/ and restart

Tip: Start small. Make one tiny change, test it, then add another. That keeps learning fun and fast.
